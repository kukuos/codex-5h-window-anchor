# Codex 5 小时额度定时刷新

每隔 5 小时 3 分钟，自动替你先跟 Codex 说一句话，让额度在上一轮结束后 3 分钟就恢复，不用等你自己想起来。

**简体中文** | [English](README.en.md)

## 先说清楚问题

Codex 的额度像一个秒表：你发出第一条消息，它就开始倒计时 5 小时，到点才把额度补满。

麻烦在于，你几点开始用，它就几点补满。比如你上午 11:23 才开始用，补满的时间就变成 16:23、21:23……整天对不上点，还经常在你正忙的时候用完。

## 怎么做到的

既然「谁先开口，倒计时就从那一刻开始」，那就让电脑在上一轮结束的第一时间抢先开口：

1. 电脑每隔 5 小时 3 分钟，自动给 Codex 发一句最短的话（短到只让它回一个 OK）。
2. 上一轮刚结束 3 分钟，这句话就到了，成为新一轮的第一条消息，新的 5 小时倒计时从这里开始。
3. 之后每一轮都这样接上，额度就一直处在「刚结束就恢复」的节奏里。

为什么是 5 小时 3 分钟，而不是整 5 小时：定时任务实际触发可能比设定时间早几分钟。按整 5 小时排，触发可能落在上一轮还没结束的几分钟里，白跑一次；多出的 3 分钟就是留给这份提前量的余量。

两个大家最关心的：

- **我正在用的时候它开口，会捣乱吗？** 不会。如果倒计时还没结束，它这句话只算在这一轮里，不会重新计时，也不会打断你；等这一轮结束，下一次自动开口会启动新一轮。
- **它这句话本身费额度吗？** 费一点点。用的是最省的发法（最轻的模型，只回一个 OK），实测每次约 1,941 token，换来额度及时恢复，可以忽略不计。

一个小提醒：触发时间不再对齐整点——因为每次间隔都比 5 小时多 3 分钟，时间会逐次往后漂 3 分钟，这是固定间隔的必然结果，不影响使用。

<details>
<summary>技术细节（想自己折腾的再看，看不懂跳过不影响使用）</summary>

每条自动消息实际执行的命令：

```bash
mkdir -p /tmp/codex-ping && cd /tmp/codex-ping && timeout 180 codex exec \
  --ephemeral --skip-git-repo-check -s read-only \
  -m gpt-6-luna -c model_reasoning_effort="low" \
  "Say OK only" < /dev/null
```

实测踩过的坑：

- 必须带 `< /dev/null`，否则 `codex exec` 会等输入而一直挂着。
- 不要用管道接这条命令，管道会掩盖真实的成功/失败结果。
- 提示词本身只占十几个字，一次 Codex 请求自带的固定开销才是大头（系统指令、工具定义等，实测约 5.9 万字符），所以省额度的关键是模型档位：最轻的 Luna + 最低推理档，而不是把提示词再缩短几个字。
- 只适用于 ChatGPT 订阅的 Codex；用 API Key 按量付费的没有这个 5 小时倒计时，不适用。
- 不要用每天固定几个整点时间的方案：实测定时任务会比整点提前约 3–4 分钟触发，可能落在上一轮还没结束的时间里白跑一次。固定间隔 + 3 分钟余量就是为了解决这个问题。

## 怎么用（给 Muse 用户）

1. 打开 [PROMPT.md](PROMPT.md)，复制里面的提示词全文。
2. 按需改开头的设置（刷新间隔、时区、要不要每次报告）。
3. 粘贴到你的 Muse 对话里，剩下的 Muse 会做完：登录 Codex、先试通一遍、建好每 5 小时 3 分钟自动执行的任务，并告诉你下次什么时候跑。
4. 平时不用管：成功不打扰你，失败了才通知。

English version: [README.en.md](README.en.md) · [PROMPT.en.md](PROMPT.en.md)

## 需要什么

- 一个能设定时任务的 Muse，Codex 装在同一台电脑上
- ChatGPT 订阅账号（Plus / Pro 等，凡是额度按 5 小时一轮恢复的套餐）

## 实测记录

这套已经在真实账号上跑通了：2026-10-27 的 18:00、22:00 和 2026-10-28 的 08:00，每次都成功把补满时间对齐到整点，每次花费 1,941 token。

搭建那天还顺带确认了一件事：额度已经用完时试发消息，Codex 提示的恢复时间和账号实际恢复时间一模一样，说明自动发的消息跟你自己用的是同一个账号、同一份额度。

2026-10-29 更新：原来每天固定 08:00、13:00、18:00、22:00 的方案，因为定时任务实际比整点提前约 3–4 分钟触发，有时会落在上一轮还没结束的时间里白跑一次，已改成现在每 5 小时 3 分钟的固定间隔方案。
